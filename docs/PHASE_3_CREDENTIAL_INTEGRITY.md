# المرحلة الثالثة — اتساق مستندات الحساب

كشفت المراجعة أن فشل تسجيل تدقيق الرفع كان يحذف الملف من التخزين بعد حفظ
بياناته، فيترك سجلًا بلا محتوى. كذلك كان فحص قابلية الإرفاق والإرسال والقرار
يسبق عمليات التخزين، دون إعادة التحقق عند الحفظ؛ فيسمح التزامن بإرفاق ملف
بعد المراجعة أو إعادة شهادة منجزة إلى الانتظار.

## المعالجة

- إنشاء الشهادة وإرفاق الملف وإرسال المراجعة وحفظ القرار تشمل سجل التدقيق
  داخل المعاملة نفسها، عبر خدمة Audit القائمة مع تمرير عميل المعاملة.
- تستخدم عمليات الإرفاق والإرسال والقرار معاملة Serializable وتكتب سجل
  الشهادة المشترك، مع إعادة قراءة حالتها قبل التعديل. إعادة المحاولة تستخدم
  آلية DatabaseService القائمة.
- تبقى اتصالات التخزين خارج معاملات قاعدة البيانات. تتم مقارنة بيانات
  الشهادة ومجموعة مستنداتها عند الحفظ مع المجموعة التي فُحصت. تغير الأدلة
  يعيد تعارضًا يتطلب تحديث الصفحة وإعادة المحاولة.
- الرفع الذي يفقد السباق مع الإرسال لا يضاف إلى الأدلة المعتمدة. تُحذف نسخته
  غير المسجلة فقط، ولا تُحذف ملفات مرتبطة بسجل محفوظ. إذا تعذر التحقق من
  نتيجة الحفظ، تُترك النسخة الخاصة بدل المخاطرة بحذف مستند محفوظ.
- تكرار المحتوى بالتزامن يعيد 409؛ ملف العملية الناجحة يبقى محفوظًا.
- لا يعيد قرار المراجعة تفعيل المستندات المؤرشفة، ولا يرسل إشعار نتيجة إذا
  تراجعت معاملة القرار. تبقى إشعارات النتائج بعد الحفظ كما في المسار القائم.

لا يتطلب التغيير ترحيل قاعدة البيانات أو تعديل الهوية البصرية. تنظيف ملفات
التخزين غير المسجلة يبقى بأفضل جهد؛ تعطل مزود التخزين قد يترك نسخة خاصة
يتطلب حذفها لاحقًا، ولا يعني ذلك نجاح الإرفاق.

## التحقق وحدود الإغلاق

اختبار `credential-integrity-db-e2e.mjs` يستخدم PostgreSQL والخدمات الفعلية
للمستندات والتدقيق والإشعارات، مع تخزين ملفات معزول للتحكم في توقيت الطلبات.
يختبر فشل التدقيق بعد كتابته، التراجع الكامل، إعادة الرفع، الملكية، التزامن،
رفعًا متأخرًا، إرسالًا متأخرًا، تغير الأدلة، الحفاظ على الأرشيف وتجاوز السياسة.
يُنفذ ضمن API validation، إضافة إلى اختبار HTTP/DB القائم الذي يتحقق من
رفع SigV4 وروابط الوصول الخاصة والصلاحيات واشتراط دليل المراجعة.

ترفض الاختبارات قواعد البيانات والخوادم غير المحلية. هذه الدفعة لا تثبت
إعداد تخزين الإنتاج أو دخول Google، ولا تغلق المرحلة الثالثة بمفردها.
