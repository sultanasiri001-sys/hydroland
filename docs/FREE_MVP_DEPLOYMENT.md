# تشغيل HYDROLAND مجاناً — نسخة MVP

## الهدف

تشغيل API لمنصة HYDROLAND مع قاعدة بيانات PostgreSQL، وربطه بالواجهة المنشورة على GitHub Pages.

التركيبة المختارة للنسخة التجريبية:

| الجزء | المزود | التكلفة |
| --- | --- | --- |
| الواجهة | GitHub Pages | 0 ريال |
| API | Render Free Web Service | 0 ريال ضمن حد الساعات المجانية |
| قاعدة البيانات | Neon Free PostgreSQL | 0 ريال ضمن حدود الخطة المجانية |

الخدمة المجانية في Render قد تدخل وضع السكون عند عدم الاستخدام؛ لذلك أول طلب بعد فترة خمول قد يتأخر. لا تُستخدم هذه التركيبة للحجوزات أو المدفوعات الحقيقية قبل الانتقال إلى خدمة مدفوعة ونسخ احتياطي.

## الخطوات المطلوبة من مالك المنصة

1. أنشئ مشروعاً جديداً في [Neon](https://neon.com) وانسخ قيمة الاتصال الكاملة `DATABASE_URL` بصيغة PostgreSQL.
2. افتح [Render](https://render.com) وسجّل الدخول بواسطة حساب GitHub الذي يملك مستودع `sultanasiri001-sys/hydroland`.
3. اختر **New → Blueprint** ثم اختر المستودع والفرع `feat/visual-experience`.
4. سيقرأ Render ملف `render.yaml` وينشئ خدمة `hydroland-api`.
5. في صفحة المتغيرات ضع قيمة `DATABASE_URL` التي نسختها من Neon. لا تضفها إلى GitHub أبداً.
6. اترك `JWT_SECRET` مولّداً تلقائياً من Render، ثم أنشئ الخدمة.
7. بعد نجاح النشر، افتح الرابط التالي للتأكد من الخدمة:

   ```text
   https://YOUR-RENDER-SERVICE.onrender.com/api/v1/health
   ```

8. أرسل رابط خدمة Render فقط إلى مسؤول التطوير. لا ترسل كلمة مرور قاعدة البيانات أو `DATABASE_URL` في المحادثة.

## ما يحدث تلقائياً

- Render يبني API داخل Docker.
- قبل تشغيل الخدمة يطبق `prisma migrate deploy`، ومنها جداول الجهات والأعضاء والمراجعات.
- CORS مقيّد على موقع GitHub Pages العام فقط.
- لا تُحفظ أسرار الإنتاج داخل المستودع.

## بعد الحصول على رابط API

يُضاف رابط الخدمة إلى إعداد واجهة HYDROLAND، وبعدها تعمل التسجيلات ولوحات الجهات والإدارة بالبيانات الحقيقية.
