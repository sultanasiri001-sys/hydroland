# المرحلة الثالثة — سلامة بيانات الحساب

## الإصلاح

كان حفظ ملف الغواص يعيد كتابة جميع الحقول، بما فيها الحقول التي لم يرسلها نموذج الواجهة. لذلك كان تعديل الجوال قد يمسح تاريخ الميلاد أو بيانات الهوية أو الملاحظات، ويعيد اللغة واللياقة الطبية إلى القيم الافتراضية.

أصبح PATCH يغيّر الحقول المرسلة فقط، ويعامل null أو النص الفارغ كطلب مسح للحقول الاختيارية. تبقى قيم الحقول المحذوفة من الطلب كما هي. يختار الخادم الحقول المسموح تعديلها صراحة، ولا يقبل تغيير ملكية الملف أو تاريخ توثيق الهوية من الطلب.

تُراجع بيانات اتصال الطوارئ بعد جمع التغيير مع السجل الموجود، داخل معاملة Serializable تستخدم آلية إعادة المحاولة الموجودة في DatabaseService. يحافظ هذا على تكامل الاسم والرقم عند التعديل الجزئي والمتزامن. يسجل التدقيق الحالة الطبية واللغة المحفوظتين فعليًا.

تعرض واجهة بيانات الغواص حالة تحميل ثم رسالة مستمرة وزر إعادة المحاولة عند الفشل. لا تتاح حقول التعديل والحفظ قبل نجاح القراءة. أما نجاح القراءة بملف غير موجود فيتيح إنشاء البيانات لأول مرة. يحافظ فشل الحفظ على المدخلات، وتُمنع الطلبات المكررة أثناء الحفظ. تستخدم هذه الحالات مكونات الحساب والهوية الحالية دون تغيير التصميم المعتمد.

## التحقق

- `profile-account-http-e2e.mjs`: قراءة وحفظ عبر HTTP وPostgreSQL، وبقاء الحقول غير المرسلة، والمسح الصريح، وعدم تغيير البيانات عند رفض الطلب، والتعديلات المتزامنة، وسلامة بيانات التدقيق وحقول الملكية.
- `diver-profile-schema-db-e2e.mjs`: تشغيل الخدمة الفعلية داخل مخطط محلي معزول يطابق ترحيل الإنتاج بمفتاح حساب UUID. يغطي إنشاء الملف وتعديله بالتزامن، بالإضافة إلى اختبارات HTTP التي تستخدم المفاتيح النصية في مخطط الاختبار الأساسي. تبقى استعلامات الملف بمعاملات SQL يحدد PostgreSQL أنواعها وفق العمود الفعلي.
- `diver-profile-integrity.spec.js`: فشل القراءة وإعادة المحاولة على الجوال والتابلت والكمبيوتر، وملف جديد فارغ، وإغلاق النموذج أثناء التحميل، والتحقق من جهة اتصال الطوارئ، ومنع تكرار الحفظ، وحفظ المدخلات عند الخطأ.
- تُحفظ صور حالات فشل القراءة ضمن ملف `account-interface-review` في CI.

لا يتطلب الإصلاح تعديل مخطط قاعدة البيانات. لا يثبت نجاح هذه الاختبارات جاهزية مزودي البريد أو Google؛ متطلباتهم موضحة في `PHASE_3_AUTH_DELIVERY.md`.
