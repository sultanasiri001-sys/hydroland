# تقييم تنبؤات الصيانة F07

يشغِّل المختص `node scripts/f07-maintenance-evaluation.mjs input.json` على نسخة مؤرخة يحق له استخدامها. يحدد مالك السياسة أفق التنبؤ وأقصى عمر مقبول لآخر قياس بالساعات. تحتفظ الجهة بالمصدر الذي يثبت أن التوقع سُجّل قبل معرفة النتيجة، وبمرجع إذن استخدام البيانات وقرار المختص.

مثال توضيحي ببيانات مصطنعة

```json
{
  "sourceRef": "synthetic-observations",
  "policyRef": "example-synthetic-policy",
  "evaluatedAt": "2030-01-04T00:00:00Z",
  "horizonHours": 24,
  "maxInputAgeHours": 5,
  "rows": [
    {
      "assetRef": "asset-example",
      "issuedAt": "2030-01-01T10:00:00Z",
      "lastMeasurementAt": "2030-01-01T05:00:00Z",
      "observedThrough": "2030-01-02T10:00:00Z",
      "predictedFault": true,
      "firstFaultAt": "2030-01-01T11:00:00Z"
    }
  ]
}
```

تُسجَّل تواريخ UTC، ويعني `firstFaultAt: null` عدم رصد عطل حتى نهاية المتابعة الموثقة. يبدأ احتساب العطل لحظة إصدار التوقع وتنتهي النافذة قبل لحظة نهاية الأفق. يمنع التداخل لنفس الأصل تكرار احتساب التعرض. تُستبعد الصفوف ذات القياس المتقادم أولًا، ثم الصفوف ذات المتابعة الناقصة. يعرض التقرير أعداد الحالات الصحيحة والخاطئة، والدقة والحساسية ومعدل الإنذارات الكاذبة. يعيد `null` لكل معدل مقامه صفر.

يراجع المختص حجم العينة وتمثيلها واختلاف الأداء بين أنواع الأصول، ويوثق قرار القبول وفق السياسة. تتطلب تغطية التأمين مرجع عقد مستقل. يبقى برنامج الصيانة الإلزامية خاضعًا لضوابطه المعتمدة.
