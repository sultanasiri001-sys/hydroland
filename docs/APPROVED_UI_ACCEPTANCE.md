# Approved UI acceptance criteria

This implementation is ready for review when:

1. Each protected role renders its own role-specific navigation and dashboard.
2. Approved HYDROLAND marine visual language is consistent across all role portals.
3. Existing role authorization, freshness checks and fail-closed behavior remain in place.
4. No role dashboard invents live operational numbers; unavailable values remain system-backed placeholders.
5. Existing Visitor and Diver flows remain unchanged functionally.
6. Responsive layouts remain usable on mobile, tablet and desktop breakpoints.
