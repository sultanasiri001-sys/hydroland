# قائمة القبول التشغيلي لبوابة مركز الغوص

هذه القائمة مخصصة لجلسة قبول محدودة في بيئة اختبار أو Sandbox. لا تُنفذ على الإنتاج، ولا تستخدم أموالًا أو بيانات عملاء حقيقية. لا تُفعّل تكامل التسوية أو بيانات مزود حقيقية أثناء القبول.

## شروط البدء

- [ ] اعتماد نسخة الاختبار ورقم الالتزام الذي ستُراجع عليه.
- [ ] تجهيز مركز اختبار معتمد وحساب موظف محاسب نشط مرتبط بالمركز.
- [ ] التأكد أن حساب الإدارة العليا `001` منفصل عن حساب المركز `00001`، وأن الحسابين لا يتشاركان الصلاحيات.
- [ ] تجهيز فاتورة ودفعة اختبارية ملتقطة في Sandbox، ومستند ترخيص اختباري غير حقيقي.
- [ ] تسجيل التاريخ والوقت والمنطقة والنسخة، من دون تدوين كلمات مرور أو رموز جلسات أو بيانات دفع.

## القبول الوظيفي للمركز

### الهوية والترخيص

- [ ] يسجل حساب المركز دخوله ويصل إلى بوابة مركزه فقط.
- [ ] تعديل الملف التجاري يحفظ الاسم والبيانات ويظهر بعد إعادة التحميل.
- [ ] رفع ملف الترخيص وتأكيد بياناته يحفظان في عملية واحدة؛ فشل الرفع لا يترك سجلًا ناقصًا.
- [ ] إرسال الترخيص للمراجعة يظهر حالة القرار وسببه للمركز، ولا يمنحه صلاحية الاعتماد لنفسه.
- [ ] حساب الإدارة العليا وحده يرى طابور الاعتماد ويتخذ القرار المسموح.

### الفريق والتدريب والرحلات والحجوزات

- [ ] دعوة عضو للفريق وتسجيل موافقته ثم إسناد الدور أو تعليقه/إعادته تعمل مع حفظ سجل الإجراء.
- [ ] ربط دورة وجلسة تدريب وحضور المتدربين يحافظ على تاريخ الجلسات والحضور.
- [ ] إنشاء رحلة وتعديلها قبل النشر ثم فتح الحجز يعمل؛ تعديل الموقع أو الوقت بعد اعتماد الطقس يلغي الاعتماد السابق بوضوح.
- [ ] عرض الحجوزات والعمليات يقتصر على المركز ويعرض حالات المشاركين والإجراءات المسموحة.
- [ ] إتمام الرحلة أو إلغاؤها يسجل الحضور والسبب والسجل المرتبط، ولا يسمح بتكرار الإجراء.

### السلامة والمعدات والتقارير

- [ ] تسجيل تقييم السلامة أو البلاغ يعرض التاريخ والحالة وسجل المركز فقط.
- [ ] تسجيل معدة وفحصها وحركتها يظهر حالة الخدمة والصيانة للمركز، ولا يمنح صلاحية مراجعة إدارية عامة.
- [ ] لوحة المركز والتقارير تعرض بيانات المركز فقط، وتستخدم اليوم والتوقيت السعودي.
- [ ] فشل تحديث البيانات يعرض رسالة قابلة للاسترداد ولا يبقي أرقامًا أو معلومات قديمة على أنها حديثة.

## القبول المالي في Sandbox

- [ ] فتح الوردية يعرض الرصيد والسجل الخاصين بالمحاسب والمركز، ويرفض العمل دون علاقة محاسب نشطة.
- [ ] طلب تسليم العهدة وقبولها يتطلبان إقرار المستلم، ويمنعان التسجيل المكرر أو اختلاف العملة.
- [ ] إنشاء مستحق يدوي من فاتورة مؤهلة يحفظ الأقساط بمجموع مطابق للمبلغ.
- [ ] تحصيل دفعة ملتقطة يخصصها مرة واحدة فقط، ويحدث الإيصال والوردية والقيد المرتبط ضمن العملية نفسها.
- [ ] إقفال الوردية يجمّد التعديلات حتى المراجعة؛ الرفض يتطلب سببًا والإعادة تحمل رقمًا جديدًا.
- [ ] تقرير الإقفال اليومي يعرض الإقفالات المعتمدة فقط ويعرض حالة اليوم الفارغ صراحة.
- [ ] إقفال الفترة يمنع الإرسال ما دامت ورديات أو مستحقات أو دفعات معلقة، ويتطلب مراجعَين مستقلين.
- [ ] استيراد كشف التسوية في Sandbox يطابق معرف الدفعة المحفوظ بدقة، ويعرض عدم تطابق المبلغ أو العملة ويمنع اعتماده.
- [ ] تأكيد أن الاستيراد لا ينشئ قيدًا جديدًا ولا يلتقط أو يعيد مبلغًا ولا يحول أموالًا.
- [ ] تأكيد أن مزود التسوية يظل غير مفعل وأن بيانات الاعتماد وإعدادات الإنتاج لم تتغير.
