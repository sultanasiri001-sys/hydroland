# HYDROLAND Training

The training capability is multi-agency by design. Recreational-diving course metadata should preserve the issuing agency and applicable standards references. HYDROLAND records must not be presented as an agency-issued certification unless an authorized issuing workflow supports that claim.

Reference architecture: WRSTC minimum recreational training framework; ISO 24801 diver levels; ISO 24802 instructor levels; ISO 24803 recreational diving service-provider requirements. Saudi regulatory and permit requirements apply independently and take precedence where applicable.
