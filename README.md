# HYDROLAND | هيدرولاند

منصة ذكية متكاملة للغوص والأنشطة البحرية والسياحة البحرية، مبنية بهيكلية قابلة للتوسع وتكاملات مستقبلية مع مزودي الخدمات والجهات الخارجية عبر طبقة تكامل مستقلة.

## الحالة الحالية
بدأ التنفيذ الفعلي للحزمة الأولى.

المسار الأول المستهدف:

إنشاء الحساب → التحقق → الملف الشخصي → طلب دور مهني → إضافة مؤهل → رفع الإثبات → إرسال للمراجعة → مراجعة بشرية → قرار → إشعار → سجل تدقيق.

## البنية الأولية
- مستودع واحد متعدد التطبيقات.
- `apps/api` لخدمة الـ API.
- واجهات API تحت المسار `/api/v1`.
- أول نقطة فحص صحية: `/api/v1/health`.
- التوثيق التنفيذي للحزمة الأولى: `docs/EXECUTION_PACKAGE_1.md`.

## مبادئ أساسية
- التسجيل لا يعني التفعيل.
- الشخص، الحساب، الدور، المؤهل، والتفويض كيانات منفصلة.
- الخادم هو المسؤول عن فرض الانتقالات بين الحالات.
- لا توجد موافقة ذاتية.
- لا حذف للتاريخ الحساس أو المالي أو الأدلة.
- الذكاء الاصطناعي يعمل فقط عبر أدوات وواجهات أعمال مصرح بها، وليس عبر وصول مباشر إلى الكود أو قاعدة البيانات.

## الخطوة التالية
بناء طبقة قاعدة البيانات والهوية والمصادقة والصلاحيات، ثم الانتقال إلى الملف المهني والمستندات وطلبات التفعيل والمراجعة البشرية.
